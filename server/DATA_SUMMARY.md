- **High:** Score > 0.8 (Critical deviations)

## 🌐 API Endpoints Available

### Clustering
```bash
GET  /api/attendance/clusters

```

### Anomaly Detection
```bash
POST /api/attendance/anomaly-train      # Train/retrain model
POST /api/attendance/anomaly-detect     # Run detection
GET  /api/attendance/anomalies          # List anomalies (supports filtering)
GET  /api/attendance/anomaly-stats      # Get statistics
PUT  /api/attendance/anomalies/:id/review  # Review/update anomaly
```

### Query Parameters for Anomalies
- `severity`: Filter by severity (high, medium, low)
- `status`: Filter by status (pending, reviewed, false_positive)
- `userId`: Filter by user
- `startDate` & `endDate`: Date range filter
- `limit` & `skip`: Pagination
